# Login และสมัครสมาชิก (ชุดทดสอบรายวิชา)

เปิดแท็บโปรไฟล์ → บัญชีของฉัน → เข้าสู่ระบบ / สมัครสมาชิกใหม่

- `/signup` สมัครบัญชีด้วยชื่อ อีเมล รหัสผ่าน และยืนยันรหัสผ่าน
- `/login` เข้าสู่ระบบด้วยบัญชีที่สมัคร
- `/register?id=...` **ลงทะเบียนเข้าร่วมกิจกรรม** เป็นคนละหน้ากับสมัครสมาชิก และต้องเข้าสู่ระบบก่อน
- Token เก็บใน SecureStore; รหัสผ่านไม่เก็บในแอป
- API ตัวอย่าง hash รหัสผ่านด้วย scrypt และ salt แยกแต่ละบัญชี ตรวจอีเมลซ้ำและตรวจสิทธิ์ที่เซิร์ฟเวอร์

## เปิด API บน Windows CMD

ในโฟลเดอร์โปรเจกต์ เปิด CMD แรก กำหนดบัญชีสำหรับทดสอบเท่านั้น (แทนค่าของตัวเอง):

```bat
set "CAMPUS_TEST_EMAIL=student@example.test"
set "CAMPUS_TEST_PASSWORD=YOUR_DISPOSABLE_PASSWORD"
npm run api:mock
```

เปิด CMD อีกหน้าต่าง ใช้ `ipconfig` ดู IPv4 ของคอมพิวเตอร์ แล้วสร้างไฟล์ `.env` ในโปรเจกต์:

```dotenv
EXPO_PUBLIC_API_URL=http://YOUR_COMPUTER_LAN_IP:4100
```

แทน `YOUR_COMPUTER_LAN_IP` ด้วย IPv4 จริง โทรศัพท์กับคอมต้องอยู่ Wi-Fi เดียวกัน และ Windows Firewall ต้องอนุญาต Node บนเครือข่ายส่วนตัว จากนั้น:

```bat
npx expo start --go --lan -c
```

อย่าใช้ `localhost` บนโทรศัพท์ เพราะจะหมายถึงตัวโทรศัพท์เอง การตั้ง URL สำหรับ Metro/tunnel ไม่ได้เปิด API port 4100 ให้โดยอัตโนมัติ

หากไม่ได้ตั้ง API ยังดูสถานที่และใช้ฟีเจอร์ในเครื่องได้ แต่ปุ่มส่งข้อมูล Login/สมัครสมาชิกจะปิดพร้อมข้อความอธิบาย

## ขอบเขต

API นี้เป็น **local classroom mock** สำหรับข้อมูลทดสอบ ไม่ใช่ระบบ production บัญชีใหม่และรายการลงทะเบียนอยู่ในหน่วยความจำของเซิร์ฟเวอร์และหายเมื่อปิด API; token เดิมจะใช้ไม่ได้หลังรีสตาร์ต API ต้องสมัคร/เข้าสู่ระบบใหม่ การรีสตาร์ตเฉพาะแอปโดย API ยังทำงานจะ restore session ได้

การใช้งานจริงต้องมี persistent database, HTTPS, token expiry/revocation, rate limiting และการยืนยันอีเมล ไม่ใช้บัญชีหรือรหัสผ่านจริงในชุดทดสอบนี้

## ตรวจด้วยตนเอง

1. เปิด API และแอป → โปรไฟล์ → สมัครสมาชิก
2. รหัสผ่านไม่ตรงกัน: แสดง error และไม่ส่งข้อมูล
3. สมัครสำเร็จ: ไปหน้ากิจกรรม และโปรไฟล์แสดงชื่อบัญชี
4. ออกจากระบบ → ลองรหัสผ่านผิด → แก้ข้อมูลแล้วเข้าสู่ระบบได้
5. รีสตาร์ตแอปโดยคง API ไว้ → restore session
6. อีเมลที่สมัครแล้ว → แสดง error พร้อมทางเข้า Login
7. เปิดกิจกรรมจาก API → ลงทะเบียนเข้าร่วม → ลองส่งซ้ำ ต้องไม่สร้างรายการซ้ำ
